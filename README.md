# Monitoramento da apuração de 2026

Coletor público para o [Observatório da apuração](https://apuracao-comparada-2026.rogeriobarbosa.chatgpt.site/).

Configuração da coleta autônoma em andamento. Fontes: Tribunal Superior Eleitoral e dados publicados pelo PET Apura (PET Ciências Sociais USP, coordenação de Manoel Galdino).

A coleta e o arquivamento de dados não significam que todos os modelos do observatório estejam em execução.
